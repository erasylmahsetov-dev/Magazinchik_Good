# Magazinchik_Good — готовый комплект для GitHub/Render

Файлы в корне специально сделаны так, чтобы их можно было загрузить через GitHub с телефона по одному или несколькими файлами:
- `index.html` — пользовательская часть
- `admin.html` — служебная часть
- `server.js` — общий сервер/API
- `package.json` — зависимости
- `db.json` — стартовая база

Для запуска на Render: Build/Install Command: `npm install`; Start Command: `npm start`. Переменная окружения `ADMIN_KEY` должна быть задана на сервере. Не публикуйте ключ и токен бота.

После запуска пользовательская часть открывается по адресу сервера, служебная — `/admin.html`.
